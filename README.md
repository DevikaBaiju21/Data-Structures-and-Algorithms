## Data Structures Implemented

### C++

**Singly Linked List**

- Insert at front, end, and any position
- Delete at head, tail, and any position
- Search, length, and display
- Reverse (in place)
- Find middle (slow/fast pointers)
- Cycle detection (Floyd's algorithm)

**Doubly Linked List**

- Insert at front, end (O(1) with tail pointer), and any position
- Delete at head, tail (O(1)), and any position
- Search, length, forward and backward display
- Reverse (swap `prev` and `next` of every node)
- Find middle (two pointers from both ends)

More will be added as I continue learning DSA.
